Tại đây liệt kê và giới thiệu các bài blog công nghệ AWS đã được dịch trong suốt kỳ thực tập:

### [Blog 1 - Bắt đầu với Healthcare Data Lakes: Sử dụng Microservices](3.1-Blog1/)
Blog này giới thiệu cách bắt đầu xây dựng data lake trong lĩnh vực y tế bằng cách áp dụng kiến trúc microservices. Bạn sẽ tìm hiểu vì sao data lake quan trọng trong việc lưu trữ và phân tích dữ liệu y tế đa dạng (hồ sơ bệnh án điện tử, dữ liệu xét nghiệm, thiết bị IoT y tế…), cách microservices giúp hệ thống linh hoạt, dễ mở rộng và dễ bảo trì hơn. Bài viết cũng hướng dẫn các bước khởi tạo môi trường, tổ chức pipeline xử lý dữ liệu, và đảm bảo tuân thủ các tiêu chuẩn bảo mật & quyền riêng tư như HIPAA.

### [Blog 2 - Healthcare Data Lake: Tìm hiểu sâu về Amazon Cognito và ABAC](3.2-Blog2/)
Giải thích cách triển khai xác thực người dùng và phân quyền truy cập dữ liệu cụ thể trong healthcare data lake sử dụng Amazon Cognito và phương pháp kiểm soát truy cập dựa trên thuộc tính (ABAC).

### [Blog 3 - Mô hình thiết kế Serverless để thu nhập dữ liệu y tế](3.3-Blog3/)
Giới thiệu mô hình serverless sử dụng AWS Lambda, S3 và API Gateway để thu thập và tiền xử lý các tệp đo lường lâm sàng một cách an toàn.

### [Blog 4 - Triển khai kiểm soát truy cập chi tiết với Amazon Cognito User Pool](3.4-Blog4/)
Thảo luận về các chiến lược bảo mật sử dụng nhóm người dùng, thuộc tính tùy chỉnh và chính sách IAM để thực thi kiểm soát truy cập chi tiết trên các API REST.

### [Blog 5 - Xây dựng quy trình xử lý dữ liệu quy mô lớn cho IoT Analytics với AWS Glue](3.5-Blog5/)
Mô tả cách cấu hình AWS Glue crawler và các tiến trình ETL để chuyển đổi dữ liệu thô từ các thiết bị IoT sang định dạng lưu trữ tối ưu.

### [Blog 6 - Bảo mật tích hợp API trong môi trường Hybrid Cloud](3.6-Blog6/)
Khám phá các mô hình thiết kế sử dụng VPC Endpoint, API Gateway authorizer và mutual TLS (mTLS) để bảo mật lưu lượng dữ liệu trong môi trường đám mây lai.
