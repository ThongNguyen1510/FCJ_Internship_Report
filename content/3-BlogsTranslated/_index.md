This section lists and introduces the AWS technology blogs translated during the internship:

### [Blog 1 - Getting started with healthcare data lakes: Using microservices](3.1-Blog1/)
This blog introduces how to start building a data lake in the healthcare sector by applying a microservices architecture. You will learn why data lakes are important for storing and analyzing diverse healthcare data, how microservices help make the system more flexible, scalable, and easier to maintain. The article also guides you through the steps to set up the environment, organize the data processing pipeline, and ensure compliance with security & privacy standards such as HIPAA.

### [Blog 2 - Healthcare Data Lakes: Diving into Cognito and ABAC](3.2-Blog2/)
Explains how to implement user authentication and authorize specific data access in a healthcare data lake using Amazon Cognito and Attribute-Based Access Control (ABAC).

### [Blog 3 - A Serverless Design Pattern for Ingesting Healthcare Data](3.3-Blog3/)
Introduces a serverless pattern using AWS Lambda, S3, and API Gateway to ingest and pre-process clinical telemetry files securely.

### [Blog 4 - Implementing Fine-Grained Access Control with Cognito User Pools](3.4-Blog4/)
Discusses security strategies using user groups, custom attributes, and IAM policies to enforce fine-grained access control on REST APIs.

### [Blog 5 - Building Scalable Pipelines for IoT Analytics using AWS Glue](3.5-Blog5/)
Describes how to configure AWS Glue crawlers and ETL jobs to transform raw IoT telemetry data into optimized storage formats.

### [Blog 6 - Securing API Integrations in Hybrid Cloud Environments](3.6-Blog6/)
Explores design patterns using VPC Endpoints, API Gateway authorizers, and mutual TLS (mTLS) to secure traffic in hybrid workloads.
