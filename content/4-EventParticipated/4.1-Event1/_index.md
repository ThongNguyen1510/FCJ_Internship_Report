# FCAJ Community Day

### Event Information
*   **Event Name:** FCAJ Community Day
*   **Date & Time:** Saturday, March 21, 9:00 AM - 12:00 PM (GMT+7)
*   **Location:** Bitexco Financial Tower, Ho Chi Minh City
*   **Objective:** Explore the latest advancements in Platform Engineering, GenAIOps, Agentic Software Development, Multimodal Generative AI on AWS, and Edge-to-Origin Content Delivery.

---

### Detailed Agenda & Highlights

#### ☁️ 09:00 - 09:45 AM | Building Modern Platform Engineering & Career Pathways
*   **Company Culture & Opportunities:** Discovering organizational culture, internship placements, and career growth tracks.
*   **Introduction to Platform Engineering:** Explored the shift from traditional DevOps to Platform Engineering. Discussed how Internal Developer Platforms (IDPs) improve developer experience (DX) and accelerate time-to-market.
*   **Interactive Q&A Session:** Engagement with industry experts regarding skills demand, emerging roles, and professional development in the cloud ecosystem.

#### ☁️ 09:45 - 10:15 AM | GenAIOps Essential - DevOps for Generative AI Applications
*   **AWS DevOps Fundamentals:** A review of fundamental DevOps pipelines on AWS tailored for AI workloads, along with recommended learning paths.
*   **GenAIOps in Production:** Practical case studies showing how to build CI/CD and deployment pipelines for Large Language Models (LLMs).
*   **Tech Stack Spotlight:** Hands-on examples using **Amazon Bedrock** (for agentic backend integration), **Amazon EKS** (for hosting scalable models), **Core Observability** components, and **Langfuse** (for tracing LLM inputs, latency, and cost).

#### ☁️ 10:15 - 10:45 AM | Shipping Code in the Agentic Era
*   **The Problem:** Managing complexity, code quality, and testing bottlenecks when using generative AI tools.
*   **The Tools:** Reviewing autonomous coding agents, IDE assistants, and workflow execution platforms.
*   **Deep Dive & Productivity Playbook:** Best practices for integrating AI agents into existing codebases. Emphasized structured prompting, prompt engineering, and safety guardrails.
*   **Live Demo:** Demonstrated an agent autonomously generating code, running local unit tests, fixing errors, and preparing a Pull Request.

#### ☕ 10:45 - 11:00 AM | Break

#### ☁️ 11:00 - 11:30 AM | Production-Grade Multimodal GenAI on AWS
*   **The New AI Application Stack:** Architecture templates showing frontend, orchestrators, vector stores, and foundation models working together.
*   **Multimodal Search:** Using **Amazon Nova Embeddings** to index and search across text, images, and video files.
*   **GraphRAG for Enterprise Knowledge:** Implementing Graph Retrieval-Augmented Generation (GraphRAG) to combine graph databases (like Amazon Neptune) with LLMs, providing highly structured factual retrieval.
*   **Multi-Agent Workflows:** Coordinating multiple specialized agents to solve complex business processes.
*   **Safety & Observability:** Setting up Bedrock Guardrails, input/output sanitization, and real-time security logs.

#### ☁️ 11:30 AM - 12:00 PM | From Edge To Origin: CloudFront as Your Foundation
*   **Amazon CloudFront for Every Workload:** Serving static assets, dynamic APIs, and media streaming globally.
*   **Cost Optimization:** Leveraging CloudFront edge caching, Origin Shield, and compression to minimize outbound data transfer (ODT) fees.
*   **Security Capabilities:** Integrating AWS Shield, AWS WAF, and SSL/TLS configurations at the edge to mitigate DDoS attacks and exploit attempts.
*   **Reliability & Performance:** Routing traffic through the AWS global backbone network to reduce latency and ensure failover resilience.

---

### Key Takeaways
1.  **Platform Shift:** DevOps is evolving towards Platform Engineering to reduce cognitive load on developers.
2.  **GenAIOps Lifecycle:** Operating GenAI in production requires specialized monitoring tools like Langfuse and Bedrock Guardrails to track prompt costs, accuracy, and safety.
3.  **Agentic Productivity:** Developer workflows are moving from manual coding to guiding AI agents, demanding strong verification and testing systems.
4.  **Advanced RAG:** Enterprise data search is shifting from simple vector search to GraphRAG for better contextual accuracy.
5.  **Edge First:** CloudFront is not just a CDN but a security and performance shield at the AWS network edge.

### Applying to Work
*   **DevOps Pipelines:** Integrate Amazon Bedrock API calls inside Lambda monitoring scripts.
*   **Observability:** Implement CloudWatch dashboard metrics to track LLM and API health logs.
*   **Security Policies:** Set up secure AWS WAF and IAM Least Privilege rules when exposing monitoring endpoints.
