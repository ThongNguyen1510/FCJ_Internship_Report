# Hệ thống giám sát Website tự động (Serverless) với Infrastructure as Code

#### Tổng quan

Trong bài thực hành này, bạn sẽ xây dựng một hệ thống tự động giám sát trạng thái hoạt động của website và cảnh báo sự cố sử dụng Amazon EventBridge, AWS Lambda, Amazon DynamoDB và Amazon SNS. Theo chuẩn DevOps hiện đại, toàn bộ hạ tầng đám mây sẽ được triển khai bằng mã nguồn Terraform (IaC).
