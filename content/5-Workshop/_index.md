# Automated Serverless Website Monitoring with IaC (Terraform)

#### Overview

In this workshop, you will build a serverless website health monitoring and alerting system using Amazon EventBridge, AWS Lambda, Amazon DynamoDB, and Amazon SNS. To align with modern DevOps practices, the entire infrastructure will be deployed programmatically using Terraform as Infrastructure as Code (IaC).
